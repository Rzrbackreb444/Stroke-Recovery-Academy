# Stroke Recovery Academy

## Overview
Stroke Recovery Academy ("REBUILD. REWIRE. RISE.") is a survivor-first stroke recovery platform designed to accelerate stroke recovery and build community. It provides recovery exercises, daily routines, an AI Sasquatch Coach, and a survivor community with accountability pairing. The platform empowers survivor-authors through a creator toolkit (Book Studio, Course Studio) to publish content and monetize it via a Marketplace with an 85/15 revenue split, aiming to disseminate effective recovery strategies and foster economic independence for survivors.

## User Preferences
Preferred communication style: Simple, everyday language.

## System Architecture

### UI/UX Decisions
The platform features a literary warm theme for the main interface and a dark OS theme for the Stroke Recovery OS. Design prioritizes mobile-first responsiveness, accessibility, and intuitive interfaces, with persistent user inputs for professional tools.

### Technical Implementations
The frontend uses React 18, TypeScript, Vite, Wouter, and TailwindCSS with Shadcn/ui. State management uses TanStack Query and custom authentication hooks. The backend is Express.js with TypeScript, adhering to RESTful API principles. Authentication leverages Replit Auth (OpenID Connect) via Passport.js, supporting email/password and Google OAuth. PostgreSQL is the primary data store, utilizing Neon serverless driver and pgvector for AI functionalities, with Drizzle ORM. The system includes a global credit system, geolocation, i18n for over 50 countries/currencies and 20 languages, and an EventEmitter-based background job processing queue with SSE streaming. Server-side rendering (SSR) is implemented for SEO on Tier-1 landing pages and blog posts, including JSON-LD and Generative-Engine SEO (GEO). Observability includes request ID tracking, structured error logging, health routes, and client-side Sentry.

- **Seven Studios**: AI-integrated content creation tools, including Book Studio and Lyrics Studio.
- **Creator Production Engine**: Tools for content vaults, SERP research, batch production, and a unified dashboard.
- **Marketplace**: Content selling platform with an 85% creator revenue share.
- **AI Integration**: Utilizes Google Gemini, OpenAI, and Lyria for various AI functionalities, including pre-LLM crisis detection for chat messages.
- **Course Social Layer**: Community features such as forums, groups, cohorts, reviews, and Live Circles (Campfire).
- **Offline PWA**: Progressive Web App with offline caching and push notifications.
- **Accountability Buddy**: System for survivor pairing and daily recovery tasks (The Bonfire).
- **Stroke Recovery OS**: Dedicated platform with a Recovery Dashboard, University, Center Finder, Blog, Sasquatch Coach (AI companion), Survivor Community, Daily Routine System, and the 66-Day Sasquatch Transformation Challenge.
- **Motivation Studio**: Tools for recovery motivation like Anthem Maker, Vision Card, and Daily Quote.
- **Recovery Anchor Studio**: Musical-mnemonic encoder grounded in Melodic Intonation Therapy.
- **Survivor Voice Cloning**: Integration with ElevenLabs Instant Voice Cloning.
- **In-App Feedback Inbox**: Public submission and admin triage.
- **Content Machine**: Admin tool for AI-generated, SEO-optimized blog drafts and infographics.
- **Podcast Pipeline**: Admin action to convert blog posts to narrated podcasts via AI.
- **Branded Onboarding**: Streamlined welcome flow for new users.
- **Daily Journey Funnel**: A single page (`/recovery/journey`) integrating daily activities: check-in, Bonfire, Coach, Anchor, Brain Gym, journal, with live completion tracking and Gemini-powered recommendations.
- **First-Run Welcome**: A five-card guided tour (`/recovery/welcome`) for new survivors covering core features, with progress persisted in `localStorage`.
- **Premium Navigation**: Global header link to `/recovery/premium` with a hover popover detailing free vs. premium features.
- **Gemini Recommendation Cards**: Contextual recommendation cards generated by `gemini-2.5-flash`, cached in-memory, with static fallbacks. Includes survivor-tone guardrails and verbatim quotes from the Nick Quote Library.
- **Nick Quote Library**: A curated collection of ~190 quotes from the founder's manuscripts and survivor rallying cries, categorized for deterministic daily quotes and feeding Gemini recommendations.
- **Today's Spark**: A deterministic Nick quote rendered above the fold on the Daily Journey and Recovery Dashboard.
- **Anonymous Coach Gate**: Implements IP-based rate limiting and an HMAC-signed cookie counter for anonymous users to provide a limited number of free messages before requiring sign-in, with ElevenLabs TTS skipped for anonymous users to manage costs.
- **Sasquatch Premium**: Monetization features including unlimited Coach access, Recovery Anchor renders, Voice Cloning, premium Campfire circles, and a 7-day free trial, available via subscriptions.
- **Premium SEO / E-E-A-T pass**: Enhancements for Marketplace Product schema, Course schema, and Nick Person `sameAs` data for improved search engine optimization and authority.
- **Coach voice + push-to-talk + latency cut (May 2026)**: Four Coach upgrades shipped together across both surfaces (the standalone `/recovery/sasquatch-coach` page AND the floating `client/src/components/recovery/SasquatchCoach.tsx` widget embedded across the app). (1) **Push-to-talk mic** uses the browser's native `SpeechRecognition` (Chrome/Edge/Safari) — free, on-device STT, no audio leaves the laptop, no added server cost. Tap mic, speak, tap to stop; final transcript drops into the input and auto-sends. Interim results render live. Capability-detected on mount; the mic button is hidden entirely on browsers that don't ship `SpeechRecognition` (Firefox today). Disabled while a turn is in flight or when the anonymous quota is spent. (2) **Latency cut: text-first / TTS-in-parallel**. Old path was `gemini → elevenlabs (~2-3s) → ship base64+text together` (~4-5s wait). New path: client sends `skipAudio: true` → server returns text the instant Gemini finishes (~1.5s) → client renders the text and *simultaneously* fires `/api/coach/speak` for the voice. Survivor reads while audio renders — roughly **3× faster perceived response**. Audio plays via a Blob URL (revoked on `onended`/`onerror` *and* on component unmount via a tracked-URLs ref) instead of base64-in-JSON, which also shrinks payloads on long replies. Crisis + sign-in-gate paths skip the parallel TTS fetch entirely. (3) **`/api/coach/speak` is now `isAuthenticated`-gated** — previously wide open, an anonymous user could curl it for free TTS bypassing the text-only quota. Verified: 401 anon, 200 signed-in. (4) **Sign-in copy realigned to founder voice**. Three-beat structure on the inline gate card: an italic founder-voice proof line ("Built by a 7-year survivor — not textbook theory, lived experience and real feedback baked in. I learned from the doctors, experimented, failed, then recovered. I'll give you the blueprint. The work is on you."), the unlock list with `voice replies + push-to-talk + unlimited turns + cancel anytime, no card needed for free` (each unlock highlighted in `#C9941A`), and the signature closer in `#C9941A`/80 italic ("Sasquatch has your back. Heart still thumpin', life's still pumpin'."). Quota hint under the input also updated to `Sasquatch's voice + push-to-talk + unlimited turns`. **Architect-caught issues fixed in same pass**: race in the parallel-TTS state update (the captured `insertedIndex` would point at the wrong message if the survivor sent another turn before TTS resolved) → dropped the `audioUrl`-stash-back-onto-message logic entirely, "Replay" button only renders for legacy inline-base64 path; mic-on-after-navigation leak (browser kept the mic indicator on if the user navigated away mid-recording) → added `useEffect` cleanup that calls `recognition.stop()` and clears the ref; Blob URL accumulation across long sessions → every minted URL is tracked in a `blobUrlsRef` and revoked on `onended`/`onerror` and on unmount.
