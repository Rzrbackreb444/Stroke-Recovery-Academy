# Stroke Recovery Academy

## Overview
Stroke Recovery Academy ("REBUILD. REWIRE. RISE.") is a survivor-first stroke recovery platform focused on accelerating recovery and fostering community. It offers recovery exercises, daily routines, an AI Sasquatch Coach, and a survivor community with accountability pairing. The platform also features a creator toolkit (Book Studio, Course Studio) for survivor-authors to publish content and a Marketplace with an 85/15 revenue split, aiming to empower survivors and disseminate effective recovery strategies.

## User Preferences
Preferred communication style: Simple, everyday language.

## System Architecture

### UI/UX Decisions
The platform features a literary warm theme for the main interface and a dark OS theme for the Stroke Recovery OS. Design principles prioritize mobile-first responsiveness, accessibility, and intuitive interfaces with persistent user inputs for professional tools.

### Technical Implementations
The frontend uses React 18, TypeScript, Vite, Wouter for routing, and TailwindCSS with Shadcn/ui components. State management is handled by TanStack Query and custom authentication hooks. The backend is built with Express.js and TypeScript, adhering to RESTful API principles. Authentication leverages Replit Auth (OpenID Connect) via Passport.js, supporting email/password and Google OAuth. PostgreSQL is the primary data store, utilizing Neon serverless driver and pgvector for AI functionalities, with Drizzle ORM for type-safe queries. The system includes a global credit system, geolocation, i18n for over 50 countries/currencies and 20 languages, and an EventEmitter-based background job processing queue with SSE streaming.

- **Daily Journey Funnel** (`/recovery/journey`): Single page that holds the whole survivor day together — streak header, 6 stepped daily activities (check-in → Bonfire → Coach → Anchor → Brain Gym → journal), per-step "completed today" computed live from existing tables (no new schema), next-up highlight, all-done celebration, plus Gemini-powered recommendation cards. Replaces the old "Today" header link target (was `/recovery/dashboard`).
- **First-Run Welcome** (`/recovery/welcome`): Five-card guided tour for new survivors covering Coach, Bonfire, Anchor, Daily Journey, and Premium. Each card has Try / Skip; progress persisted in `localStorage`. Lands the survivor on `/recovery/journey` when finished. Premium card flagged Optional, never blocking.
- **Premium Nav (Global Header)**: Always-visible "Premium" link with Sparkles icon + amber accent. Hover popover shows 4-line free-vs-premium snapshot (Coach 25/day → unlimited, Anchors 3/mo → unlimited, Voice Cloning included, premium Campfire). Single click → `/recovery/premium`. Never modal, never blocking.
- **Gemini Recommendation Cards** (`/api/recovery/recommendations?surface=...`): Inline contextual recommendation cards with quote + body + deep-link CTA. Generated by `gemini-2.5-flash` per `(userId, surface, day)` and cached in-memory for 24h; static hand-curated fallback rotation when Gemini unavailable so the surface never empties out. Reusable `<RecommendationCards surface="..."/>` component, mounted on Daily Journey, Welcome, **Recovery Dashboard, and Sasquatch Coach (gated to the empty-state — only renders before first user message so it never interrupts an in-flight conversation)**. Per-card 7-day dismissal via `localStorage`. Survivor-tone guardrails baked into the prompt (no emoji, no exclamation points, no marketing jargon, never recommend already-completed steps, never recommend Premium when streak < 3 OR no steps completed today). **Quote field is anchored to Nick's actual voice** — see Nick Quote Library entry below.
- **Nick Quote Library** (`server/data/nickQuotes.ts`): ~190 curated quotes pulled directly from Nick Kremers' source manuscripts (Sasquatch Doctrine + Creed, Stroked-Out Sasquatch Manifesto, Ultimate Stroke Recovery Bible 2025, ICU Hell chapter) plus survivor-supplied rallying cries the founder uses verbatim ("Heart still thumpin', life's still pumpin'"). Organized into 13 categories (foundation, ownership, movement, reflection, repetition, adaptation, humanhood, fuel, dark, identity, humor, doctrine, practice). Three integration points: (1) `sampleQuotePool({surface, streak, isPremium})` feeds 8 candidate quotes into the Gemini recommendations prompt as a STRICT requirement that the model copy `quote` verbatim from the pool — eliminates the "generic motivational copy" drift Gemini gravitates toward and guarantees every card reads as Nick. (2) `STATIC_FALLBACK` quotes in `recoveryJourneyRoutes.ts` are sourced from the library so the platform reads on-brand even when the LLM path is degraded. (3) `getDailyQuote(userId)` is deterministic per `(userId, UTC-day)` using FNV-1a hash — same survivor sees the same line all day, fresh quote at UTC midnight, no DB writes. Surface-tuned weighting: Coach gets humanhood + dark + humor + fuel; Dashboard gets practice + movement + repetition; Welcome gets foundation + identity. Streak-aware: streak<3 boosts foundation + dark so first-week survivors hear "you're still here, it counts" before they hear "stack the failures". Dark-category quotes are honest (acknowledge depression, the void, "never" verdicts) but always swing forward — never toxic-positive.
- **Today's Spark** (`/api/recovery/spark` + `<TodaysSpark/>`): Single deterministic Nick quote rendered above the fold on Daily Journey + Recovery Dashboard. Pure library lookup (no LLM call, no DB write), returned by `getDailyQuote(userId)` from the Nick Quote Library. Card design: amber gradient on stone-900, Quote icon, "Today's Spark" eyebrow, quote in amber-100, attribution line "— Nick Kremers, founder &amp; 7-year survivor". Renders text via React (never `dangerouslySetInnerHTML`), so the quote-data path is XSS-clean by construction.
- **Quote-pool determinism + verbatim guard (architect-hardened May 2026)**: Three concerns surfaced by code review of the Nick Quote Library wiring were fixed in the same pass. (1) `sampleQuotePool()` previously used `Math.random` via `getQuotesByCategory`, so a server restart mid-day could regenerate a different candidate pool on the next Gemini cache miss — survivor would see two different sets of recommendations within the same calendar day. Now seeded with a `mulberry32` PRNG keyed on `${userId}::${surface}::${UTC-day}`, so the pool is stable across restarts/cache evictions for the same survivor on the same day. (2) Gemini was instructed to copy `quote` verbatim from the pool but the parse path only validated `quote.length > 0` — a paraphrase would have shipped. Added `quotePoolSet.has(rawQuote)` guard at the parse seam; on mismatch the card falls back to the first library quote in the pool, so every shipped card is guaranteed to be in Nick's actual voice. (3) Coach-surface visual collision: RecommendationCards initially mounted *above* the existing "Quick actions" + STARTER_PROMPTS block on the Coach empty state, both pitching `/recovery/today` + `/recovery/motivation` (choice paralysis). Moved the cards to *below* the starter prompts as "further reading" — primary CTAs stay primary, the curated Nick-quote card sits as the optional next step.
